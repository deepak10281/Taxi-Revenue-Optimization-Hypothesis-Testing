# Taxi Revenue Optimization – Hypothesis Testing

This repository contains hypothesis testing and analysis
on NYC Yellow Taxi trip data.

## Dataset

The full dataset is too large to be hosted on GitHub.

Source (Kaggle):
https://www.kaggle.com/datasets/gauravpathak1789/yellow-tripdata-2020-01

File used:
yellow_tripdata_2020-01.csv

For convenience, a cleaned sample (under 25MB) is included:
Cleaned_Data_25MB.zip

## Tools Used
- Python (Pandas, NumPy, SciPy)
- SQL
- Jupyter Notebook
